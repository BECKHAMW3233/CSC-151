# CSC-151 — Java Programming

Coursework repository for **CSC-151 (0901) — JAVA Programming**, Fall 2026, Fayetteville Technical Community College.

**Instructor:** David Teter (teterd@faytechcc.edu)
**Term:** 08/17/2026 – 12/12/2026

## About This Course

This course introduces computer programming using the Java programming language with object-oriented programming principles. Emphasis is placed on event-driven programming methods, including creating and manipulating objects, classes, and using object-oriented tools such as the class debugger.

## Repository Contents

This repo stores class files, including:
- Individual project code
- Group project contributions
- Module exercises and screenshots-related code
- Practice/reference programs
